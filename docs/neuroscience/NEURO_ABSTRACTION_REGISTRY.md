# Neuroscience Abstraction Registry

Status: Slice NEURO-001 registry foundation.

This registry prevents neuroscience scope loss. It does not reduce the Brain to a chatbot, LLM wrapper, money engine, dashboard, source registry or V0 proof harness. It preserves multi-scale neuroscience and cognitive architecture while requiring every concept to become executable, testable or explicitly tracked as unknown.

## Scope doctrine

1. Preserve every material neuroscience, cognitive, speculative, unknown, disputed, future and research concept unless explicitly rejected by Tyler or prohibited by safety/legal constraints.
2. Staging is not deletion.
3. Conflicting theories are preserved as competing theories.
4. Unknown mechanisms are not converted into fake certainty.
5. Brain-region analogies are software translations, not literal equivalence claims.
6. Dreams, simulations, predictions and hypotheses cannot become facts without evidence.
7. No abstraction may be marked complete without schema, service, table, state, fixture, test, dashboard/control surface and acceptance evidence.

## Abstraction status taxonomy

- `implemented`: code, tests, fixtures and acceptance evidence exist.
- `provisional`: implemented or mapped as a useful functional approximation, but not a biological equivalence claim.
- `disputed`: credible competing theories exist and must be preserved.
- `unknown`: biological mechanism is not mechanistically understood enough to implement honestly.
- `speculative`: proposed software analogy requires future testing before operational trust.

| L0 | Resource substrate | Compute, memory, latency, storage, model-call budget and operator burden. |
| L1 | Global modulation | Neuromodulatory, homeostatic and affective control signals. |

| L3 | Synaptic topology | Edge weights, evidence linkage, plasticity, pruning, decay and rewiring. |
| L4 | Microcircuits | Reusable compare, gate, amplify, suppress, bind, route and sequence motifs. |
| L5 | Brain regions and organs | Functional software translations of region/system roles. |
| L6 | Global cognitive state | Attention, arousal, uncertainty, conflict, fatigue and pressure fields. |
| L7 | Workspace attention | Current contents of mind proxy and broadcast surface without consciousness claims. |
| L8 | Self-model and policy | Identity, protected goals, capabilities, limits and self-modification gates. |
| L9 | Body and tools | Files, APIs, GitHub, databases, dashboards, communication channels and permissions. |
| L10 | Social/world model and defense | Counterparties, institutions, trust, threats, immune alerts and world state. |
| L11 | Development, sleep and evolution | Maturation, replay, consolidation, dreams, decay, recovery and self-improvement. |

## Unknown and disputed mechanisms

Unknown, disputed and speculative mechanisms are preserved as first-class build inputs. They may receive schemas, fixtures and tests, but they must not be marked as implemented biological equivalence.

Examples:

- consciousness mechanism
- subjective experience
- binding problem
- selfhood continuity
- dream function
- intuition
- unconscious processing
- memory reconsolidation boundaries
- embodied cognition dependency

## Implementation mapping rule

A neuroscience concept receives GO only when one of these is true:

1. It is implemented with owner object, schema, service, table, state machine, fixture, test, dashboard/control surface and acceptance evidence.
2. It is explicitly preserved as unknown, disputed, speculative or research debt with competing hypotheses and HOLD status.

Silent omission is not allowed.
