# Multi-Scale Cognition Stack

Status: Slice NEURO-002 multi-scale cognition map.

The Brain must not collapse into a flat list of modules. This stack preserves layers from compute substrate through self-improvement. Each level can be implemented, simulated, represented as research debt or held as a future layer, but it may not be silently deleted.

## Stack levels

| Level | Name | Role | Software owner |
|---|---|---|---|
| L0 | Resource substrate | compute, memory, latency, storage, model calls, operator burden | ResourceState |
| L1 | Global modulation | arousal, affect, precision, stress, curiosity, urgency | AffectiveStateSnapshot |
| L2 | Synthetic cellular primitives | activation, inhibition, fatigue, threshold and refractory analogs | SyntheticCognitiveCell |
| L3 | Synaptic topology | graph edges, weights, provenance, decay, plasticity and rewiring | GraphEdge |
| L4 | Microcircuits | compare, gate, amplify, suppress, bind, route and sequence motifs | MicrocircuitPattern |
| L5 | Brain regions and organs | functional region/system translation layer | BrainRegionFunction |
| L6 | Global cognitive state | conflict pressure, attention state, memory pressure, uncertainty | CognitiveStateSnapshot |
| L7 | Workspace attention | selected current contents, suppressed alternatives and broadcast trace | GlobalWorkspaceFrame |
| L8 | Self-model and policy | identity, protected goals, limits, permissions and self-modification gates | SelfModelSnapshot |
| L9 | Body and tools | files, APIs, GitHub, databases, dashboards, communications and permissions | ToolBodyState |
| L10 | Social/world model and defense | counterparties, institutions, risks, immune alerts and world model | CognitiveImmuneEvent |
| L11 | Development, sleep and evolution | maturation, replay, consolidation, decay, retraining and mutation | DevelopmentalStage |

## Cross-scale rule

Higher scales may depend on lower scales, but they may not overwrite lower-scale evidence or erase uncertainty. Lower scales may constrain higher cognition through resource pressure, latency, safety, provenance and permission boundaries.

## Acceptance rule

The stack receives GO only when every L0-L11 level is represented, each level has owner object, service, table, state machine, dashboard and acceptance criteria, and no level claims full biological equivalence.
