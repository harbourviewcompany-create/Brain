# Brain Neuroscience Abstraction Layer

This directory is the control surface for neuroscience-derived Brain architecture.

The purpose is not decorative analogy. Every neuroscience abstraction must either map to executable artifacts or remain explicitly preserved as unknown, disputed, speculative, future or research debt. Staging work by V0/V1/V2/V3/V4 does not delete scope.

## Non-claims

The Brain does not claim full human-brain equivalence, phenomenal consciousness, sentience, solved neuroscience or complete implementation. If a biological mechanism is unknown or disputed, the repo must preserve that uncertainty as a first-class object.

## Required artifact chain

Every accepted abstraction maps to:

- owner object
- schema
- runtime service
- database table
- state machine
- formula or algorithm where applicable
- fixture
- test
- dashboard or control surface
- acceptance criteria
- source-to-build traceability
- GO/HOLD status

## Files in this layer

- `NEURO_ABSTRACTION_REGISTRY.md`: master abstraction doctrine and registry rules.
- `BRAIN_REGION_SOFTWARE_MAP.md`: functional brain-region-to-software translation map.
- `MULTISCALE_COGNITION_STACK.md`: L0-L11 cognition stack and cross-scale dependencies.
- `UNKNOWN_MECHANISM_REGISTRY.md`: control rules for unresolved, disputed and speculative mechanisms.
- `THEORY_CONFLICT_REGISTRY.md`: control rules for competing neuroscience theories.
- `GLOBAL_WORKSPACE_PROXY.md`: bounded workspace access, competition, suppression and broadcast proxy.
- `json/neuro-abstraction-registry.json`: machine-readable abstraction registry for validation.
- `json/brain-region-map.json`: machine-readable brain-region mapping registry.
- `json/multiscale-cognition-stack.json`: machine-readable L0-L11 stack registry.
- `json/unknown-mechanism-registry.json`: machine-readable unknown-mechanism HOLD registry.
- `json/theory-conflict-registry.json`: machine-readable theory conflict registry.
- `json/global-workspace-proxy.json`: machine-readable global workspace proxy registry.

Future files will add memory, perception, action, affect, self-model, immune, development, sleep and reality-boundary systems.
