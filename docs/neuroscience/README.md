# Brain Neuroscience Abstraction Layer

This directory is the control surface for neuroscience-derived Brain architecture.

The purpose is not decorative analogy. Every neuroscience abstraction must either map to executable artifacts or remain explicitly preserved as unknown, disputed, speculative, future or research debt. Staging work by V0/V1/V2/V3/V4 does not delete scope.

## Non-claims

The Brain does not claim full human-brain equivalence, phenomenal consciousness, sentience, solved neuroscience or complete implementation. If a biological mechanism is unknown or disputed, the repo must preserve that uncertainty as a first-class object.

## Required artifact chain

Every accepted abstraction maps to:

- owner object
- schema
- runtime service
- database table
- state machine
- formula or algorithm where applicable
- fixture
- test
- dashboard or control surface
- acceptance criteria
- source-to-build traceability
- GO/HOLD status

## Files in this layer

- `NEURO_ABSTRACTION_REGISTRY.md`: master abstraction doctrine and registry rules.
- `json/neuro-abstraction-registry.json`: machine-readable registry for validation.
- Future files will add brain-region maps, theory registries, unknown mechanisms, workspace, memory, perception, action, affect, self-model, immune, development, sleep and reality-boundary systems.
