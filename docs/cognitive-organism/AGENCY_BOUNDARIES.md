# Agency Boundaries

Cognitive Organism V1 can observe, think, prepare, recommend and request approval. It cannot perform unapproved external action.

## Tiers

- Tier 0: observe
- Tier 1: think
- Tier 2: prepare
- Tier 3: recommend
- Tier 4: act with approval
- Tier 5: limited autonomy, HOLD in V1
- Tier 6: prohibited

Tier 4 requires explicit approval. Tier 5 is not enabled. Tier 6 is blocked.

External outreach, publishing, spending and consequential messages remain approval-gated.
