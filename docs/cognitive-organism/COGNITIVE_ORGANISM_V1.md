# Cognitive Organism Layer V1

Status: GO for deterministic, approval-gated implementation slice. HOLD for literal consciousness claims, live external actions, Tier 5 autonomy and production outreach.

The Cognitive Organism Layer turns The Brain from a collection of cognition and revenue primitives into a governed functional consciousness proxy.

It does not claim subjective experience. It implements a persistent global workspace where perception, memory, goal pressure, uncertainty, internal conflict and action pressure are integrated into a self-state that guides future behavior.

## V1 modules

1. Self-model
2. Goal pressure system
3. Global workspace
4. Curiosity engine
5. Imagination engine
6. Originality engine
7. Dream/consolidation cycle
8. Internal debate
9. Cognitive immune system
10. Governed agency
11. Development timeline
12. Cockpit surface

## Functional loop

```text
memory refs + signal refs
-> workspace admission
-> curiosity task
-> original idea from memory
-> internal debate
-> immune screen
-> approval-gated agency proposal
-> dream insight
-> self-state update
-> development event
```

## Hard boundaries

- No literal consciousness claim.
- No autonomous outreach.
- No unapproved spending.
- No live scraping without access review.
- No dream insight becomes fact without evidence.
- No original idea becomes action without skeptic review.
- Tier 5 autonomy is HOLD in V1.
- Tier 6 actions are prohibited.

## Acceptance

V1 is accepted when tests prove self-state, goal pressure, workspace admission, curiosity generation, originality rejection, dream insight generation, internal debate, quarantine, governed agency and replay all work deterministically.
