# Brain Function Map — Implementation Registry

This is deliberately a registry, not a claim that neuroscience has a complete specification of the human brain.

| Biological / cognitive function | Software analogue | Status |
|---|---|---|
| Sensory input | Source connectors + observations | schema ready |
| Salience | Attention market | implemented v0 |
| Working memory | bounded active context / scratch state | planned |
| Episodic memory | immutable event ledger | schema ready |
| Semantic memory | entities, facts, beliefs | implemented v0 |
| Associative memory | graph topology + vector retrieval | schema ready |
| Synaptic plasticity | typed edge reinforcement/weakening/pruning | implemented v0 |
| Prediction error | contradictions + forecast/outcome difference | partial |
| Belief formation | evidence-weighted confidence transitions | implemented v0 |
| Forgetting | confidence/edge decay | partial |
| Curiosity | uncertainty-reduction tasks | implemented v0 |
| Dreaming / consolidation | offline recombination | implemented v0 |
| Executive inhibition | governance governor | implemented v0 |
| Reward learning | outcome reward function | implemented v0 |
| Resource seeking | capability investment model | implemented v0 |
| Planning | action candidates + simulation | planned |
| Counterfactual reasoning | alternate-state graph simulation | planned |
| Causal reasoning | causal edge types + intervention models | planned |
| Metacognition | confidence calibration + model self-audit | planned |
| Language | pluggable model adapter | planned |
| Spatial cognition | geospatial/scene models | research surface |
| Motor control | external action adapters | gated / planned |
| Emotion | multi-dimensional regulatory state, not fake text emotion | research surface |
| Homeostasis | compute/cost/risk/resource state regulation | planned |
| Social cognition | actor models + theory-of-mind hypotheses | research surface |
| Consciousness | no accepted engineering specification | unknown / research surface |
| Subjective experience | no accepted implementation test | unknown |
