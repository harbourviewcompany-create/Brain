# Research Boundaries

The project can aim to implement every *identified* brain function, but it cannot truthfully claim to reproduce every aspect of a human brain today. Neuroscience does not possess a complete mechanistic specification of consciousness, subjective experience, whole-brain learning, neuromodulation, memory consolidation, emotion, embodiment, or many cross-scale interactions.

The codebase therefore uses a **function registry**. Every known or hypothesized function can receive:

- a biological description,
- confidence in the scientific model,
- a software analogue,
- implementation status,
- tests/benchmarks,
- dependencies,
- revision history.

Unknown functions are not discarded. They remain explicit research surfaces rather than being filled with invented certainty.
