# Developmental Plasticity Model

Purpose: connect outcome-grounded learning to the existing developmental intelligence architecture without claiming biological equivalence.

## DevelopmentalPlasticityDelta
Fields: id, target_kind/id, trigger_learning_event_ids, before_state_ref, proposed_after_state, mechanism_class, expected_benefit, regression_risk, evidence_refs, benchmark_refs, rollback_plan_ref, lifecycle_state, created_at/applied_at.

Mechanism classes are software abstractions such as weight_adjustment, routing_preference, retrieval_priority, attention_policy, calibration_update, graph_rewire, strategy_preference, self_model_competence_update. They must not be labeled as literal synaptic/neural equivalence unless supported by existing neuroscience certainty controls.

## Rules
- Outcome evidence and attribution precede durable plasticity.
- Existing AGENT-017–021 benchmark/improvement controls remain authoritative.
- Significant changes require pre/post benchmark evidence and rollback capability where current doctrine requires it.
- Cognitive-immune and governance checks remain applicable.
- Plasticity is append-only/superseding in history; prior state is replayable.
- Unknown biological mechanisms stay registered as unknown.

## Cross-system targets
Memory retrieval, belief calibration, graph association, model routing, curiosity priority, attention allocation, planning policy, resource allocation and self-model competence may receive governed deltas. Full autonomous self-rewriting remains HOLD unless separately approved and accepted.
