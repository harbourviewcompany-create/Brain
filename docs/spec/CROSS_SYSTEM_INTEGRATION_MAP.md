# Cross-System Integration Map

This map specifies consumers/producers; it does not claim all wiring is complete.

| Organ/system | Produces | Consumes | Required delta |
|---|---|---|---|
| Source/Perception | observations, percepts, evidence lineage | source reliability, attention state | protocol envelope + provenance |
| Attention/Global Workspace | attention selections/workspace admissions | epistemic state, salience, goals, affect | attention provenance and projection stage |
| Belief/Truth Maintenance | beliefs, contradictions, predictions | evidence/provenance, epistemic state | multi-axis epistemic snapshots |
| Memory systems | episodic/semantic/procedural/prospective records | provenance, lifecycle, learning deltas | shared protocol adaptation |
| Curiosity | investigation tasks/affordances | KnowledgeGap | gap-driven rationale trace |
| Conflict/Debate/Executive | conflict resolution/decision | Conflict, epistemic state, goals/resources | general arbitration contract |
| Planning/Simulation | plans, counterfactuals | CognitiveAffordance, beliefs/models | affordance and provenance linkage |
| Affect/Homeostasis/Neuromodulation | state/modulation signals | outcomes, percepts, goals | protocol references; no forced theory |
| Cognitive Immune | quarantine/clearance decisions | candidates, provenance, risk | conflict/projection integration |
| Self Model | competence/state estimates | outcomes, learning events | plasticity deltas and provenance |
| Sleep/Dream/Consolidation | generated hypotheses/reconsolidation | memories/gaps | origin labels; no evidence masquerade |
| Development | plasticity proposals/applied deltas | LearningEvent, benchmarks | developmental plasticity contract |
| Action/Governance | projection/action/outcome | decision, affordance, approval | explicit projection boundary |
| Observability/Operator | replay/inspectors | all above | standard replay bundle and gap/conflict surfaces |

## Integration order
Protocol → epistemic/provenance → gap/affordance → projection/outcome/replay → organ adapters → developmental feedback → operator surfaces.
