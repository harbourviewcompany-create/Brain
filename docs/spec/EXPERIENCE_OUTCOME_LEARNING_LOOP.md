# Experience → Outcome → Learning Loop

Purpose: unify existing outcome/reward/attribution/developmental systems into a cross-cognitive lineage without replacing MOD-007 or economic attribution.

## Canonical loop
Perception/Memory → Belief/Model → Prediction/Goal → Affordance/Plan → Decision → Action → Outcome → Prediction Error/Attribution → LearningEvent → governed cognitive change.

## LearningEvent
Required: id, outcome_refs, prediction_refs, action_refs, attribution_refs, evidence/provenance refs, expected_vs_actual summary, utility_delta, information_gain, confidence_delta, proposed_updates, lifecycle_state, created_at.

Proposed updates may target belief calibration, source trust, retrieval weights, graph weights, model routing, strategy preference, attention priority, curiosity priority, planning policy, resource allocation or self-model competence estimates.

## Hard gates
- No major learning without outcome attribution.
- Proposed self-modification remains subject to existing benchmark, cognitive-immune, rollback and approval requirements.
- Learning changes are append/supersede operations; historical state remains reconstructable.
- Failed actions are learning evidence and cannot be silently dropped.
- Economic attribution remains a specialized downstream implementation, not the generic learning contract.

## Developmental integration
Repeated validated LearningEvents may generate DevelopmentalPlasticityDelta objects; their application must be measurable, reversible where required and benchmarked against existing competence baselines.
