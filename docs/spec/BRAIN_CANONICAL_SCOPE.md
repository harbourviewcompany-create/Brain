# Brain Canonical Scope

The Brain scope is preserved by default. This document prevents agents from narrowing the project.

## Primary economic objective

The Brain is a general cognitive runtime with an explicit capital-discovery objective layer. The cognitive substrate exists to perceive, model, reason, learn, and act; the Capital Discovery Cortex uses those capabilities to detect monetizable change, validate it, route it toward controllable transactions, learn from realized economic outcomes, and compound capital and proprietary assets.

Canonical economic chain:

`WORLD MOVEMENT -> PERCEPTION -> CHANGE -> PRESSURE -> ASYMMETRY -> AFFORDANCE -> OPPORTUNITY -> MONEY PATH -> TRANSACTION -> REVENUE/PROFIT -> ATTRIBUTION -> LEARNING -> CAPITAL ALLOCATION -> COMPOUNDING`

The economic objective optimizes risk-adjusted net economic value under capital, operator-attention, legal, trust, and execution constraints. Revenue alone is not the target.
