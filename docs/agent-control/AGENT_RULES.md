# Agent Rules

These rules bind all AI agents working in this repo.

## Preserve by default

Every material concept is preserved unless it is an exact duplicate, unreadable, explicitly rejected by Tyler, safety-prohibited, or confirmed unrelated.

## No narrowing

Agents may stage work by V0/V1/V2/V3/V4, but staging is not deletion. Later-stage concepts remain in scope.

## No silent synthesis

Agents must not replace source concepts with a cleaner assistant architecture. If concepts conflict, preserve both and log the conflict.

## Approval-gated external action

Internal cognition may run automatically. External consequences require approval. External consequences include outreach, introductions, spending, publishing, legal claims, client claims, deal commitments, and sensitive conclusions.

## Formula traceability

Every score must have: formula ID, version, inputs, output, owner object, service, storage target, dashboard surface, decision consequence, and test.

## Attribution before learning

Reward, pain, graph rewiring, source promotion, strategy promotion, and capital reallocation require outcome attribution. Low attribution blocks major learning.

## Deterministic replay

Every fixture-backed run must replay from seed with the same objects, formula runs, state transitions, and GO/HOLD result.

## Test before complete

No agent may mark a ticket complete without listing tests run and acceptance evidence produced.

## No claim without evidence

Do not claim a feature is built, proven, safe, deployed, calibrated, or operator-grade unless the relevant code, tests, fixtures, replay, and acceptance report exist.
